# AI routine import — prompt examples and sample (Phase 5.4c)

These prompts are generated by the app from **only** the options the user ticks. Room names are off by default. The app never contacts an AI service: the user copies the prompt into an AI tool of their choice and pastes the JSON back. HomeHub then validates it, shows a preview, and saves nothing until the user confirms.

## English example

Ticked: kitchen, bedroom, airfryer; 30 minutes; one problem; templates requested.

```text
You are designing a home-cleaning plan for the HomeHub app. Output ONLY one JSON object matching the schema below — no prose, no Markdown fences.

# Problems to solve
- Dishes pile up in the evening

# Home (only what the user chose to share)
areaType: kitchen, bedroom
deviceType: airfryer
Time available per day (minutes): 30

# Rules
- schemaVersion: 1, packageType: "homehub-cleaning-plan"; at most 100 tasks and 50 templates.
- Each item uses EXACTLY ONE of areaType (bedroom, kitchen, bathroom, living, entrance, balcony) or deviceType (ac, dishwasher, fridge, airfryer, vacuum, microwave, stove).
- frequency: {"type":"daily"} | {"type":"interval","unit":"day"|"month","n":N (days ≤ 365, months ≤ 12)} | {"type":"weekly","weekday":0-6} | {"type":"monthly","day":1-31}.
- Device items may set triggerType: periodic | afterUse | afterCycle | inSeason | seasonStart | seasonEnd (afterUse/afterCycle/seasonStart/seasonEnd: no frequency). Do NOT use conditionBased or manual.
- estimatedMinutes: whole number 1–240. priority: low | normal | high. title ≤ 80 characters (titleEn optional). note/reason ≤ 300. No links, no ids, no dates, no extra fields.

# Schema example
{
  "schemaVersion": 1,
  "packageType": "homehub-cleaning-plan",
  "metadata": {
    "name": "Plan name",
    "language": "en"
  },
  "tasks": [
    {
      "title": "Wipe the kitchen counter",
      "areaType": "kitchen",
      "frequency": {
        "type": "daily"
      },
      "estimatedMinutes": 5,
      "priority": "normal",
      "note": "",
      "reason": ""
    }
  ],
  "templates": [
    {
      "pack": "Weekend",
      "title": "Clean the fridge",
      "deviceType": "fridge",
      "triggerType": "inSeason",
      "frequency": {
        "type": "interval",
        "unit": "month",
        "n": 1
      },
      "estimatedMinutes": 20
    }
  ]
}
```
