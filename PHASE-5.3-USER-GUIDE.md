# HomeHub — Phase 5.3 User Guide / دليل المستخدم

## Home Routine & Cleaning (التنظيف)

Open **Cleaning** from the menu (on a phone: **More → Cleaning** if it isn't on the bottom bar).

- **Today:** what is due today, with progress ("2 of 5 done today").
- **My tasks:** tasks assigned to you, or that you claimed.
- **Shared available:** shared tasks nobody has claimed yet.
- **Upcoming:** the next two weeks.
- **Overdue:** the most recent missed date of each task. If a daily task was missed for a week, you see **one** item ("missed 7 times"), not seven.
- **Done:** completed in the last week.
- **Manage tasks:** every task, including archived ones.
- Use the **Room** filter to see one room only.

**Create a task** (adults with permission): **New task**, then fill in:
- the name and optional instructions;
- a room and a priority;
- **Who does it:**
  - **Assigned:** pick 1–5 people.
  - **Shared:** anyone eligible can claim it. Ticking nobody means every adult; children only see shared tasks they are ticked for.
- **Repeat:** once (with a due date), every N days, chosen weekdays every N weeks, or monthly on a day. Choosing 31 means the last day of shorter months.
- **Start** date and an optional **end** date.

**Doing a task:**
- **Claim** reserves a shared task for you, so others see "Claimed by …". If two people press Claim at the same moment, only the first succeeds and the other is told.
- **Done** marks it complete, with an optional note.
- **Release** gives a claimed task back.
- **Reopen** puts a completed task back if it wasn't finished. A reason is required, and the completion stays in the history.
- **History** shows who claimed, completed or reopened it, and when.

**Archive / Restore** (admins): an archived task stops appearing; its history is kept.

## Edit the active 10-day budget (تعديل الميزانية)

**Expenses → Budget → active period → Edit budget** (only for people who can manage that wallet's budgets).

1. You see the current budget, spent, remaining, days left and daily allowance.
2. Type the **new budget** (0 or more, at most 2 decimals) and watch the preview: remaining and daily allowance, before → after.
3. If the new amount is **below what's already spent**, you get a warning. The period shows as over budget, and no expense is deleted.
4. Optionally add a **reason**, then **Save new budget**.

What changes: **only the target amount.** Dates, length, wallet, currency, expenses and wallet balances stay exactly as they are; a budget is a target, not money. Every change is kept under **Budget changes** (old → new, who, when, reason).

If someone else changed the budget at the same moment, you'll see "Someone changed this budget a moment ago". Close the window, check the new amount, and try again.

**بالعربية باختصار:**
- **التنظيف:**
  - «اليوم» و«مهامي» و«مشتركة متاحة» و«القادمة» و«المتأخرة» و«المنجزة».
  - **حجز** للمهمة المشتركة (يفوز الأسبق)، و**تم** للإنجاز، و**إلغاء الحجز**، و**إعادة فتح** مع سبب إلزامي، و**السجل** لكل الإجراءات.
  - المهمة اليومية الفائتة تظهر مرة واحدة فقط مع عدد مرات الفوات.
  - الأطفال يرون وينفذون فقط المهام المحددة لهم.
- **تعديل الميزانية:**
  - من المصروفات ← الميزانية ← الفترة النشطة ← «تعديل الميزانية».
  - يتغير المبلغ المستهدف فقط، لا التواريخ ولا المدة ولا الأرصدة.
  - يظهر تحذير إذا كان المبلغ أقل مما صُرف.
  - كل تعديل محفوظ في «تغييرات الميزانية».
